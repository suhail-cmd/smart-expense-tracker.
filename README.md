# Smart Expense Tracker

An AI-powered tool that automatically categorizes bank transactions using **TF-IDF + Naive Bayes**, with an interactive Streamlit dashboard for spending insights.

Built this after manually sorting my own UPI transactions into spending categories for the tenth time — decided to automate it.

## What it does

- Takes raw transaction descriptions (e.g. `UPI/SWIGGY/406812345678/Payment`) and predicts a spending category (Food, Travel, Shopping, Bills, Entertainment, Income)
- Cleans messy real-world bank statement formats into a usable structure
- Displays categorized transactions and a spending breakdown in a live dashboard

## How it works

1. **Data cleaning** (`00_clean_bank_statement.py`) — converts raw bank exports (separate Debit/Credit columns, noisy UPI reference numbers) into a clean `date, description, amount` format.
2. **Model training** (`02_train_classifier.py`) — vectorizes transaction descriptions using **TF-IDF**, then trains a **Multinomial Naive Bayes** classifier to predict category from the text.
3. **Dashboard** (`03_dashboard.py`) — a Streamlit app where you upload a CSV and instantly see categorized transactions plus a spending summary chart.

## Results

Tested on a held-out set of transactions the model never saw during training:

- **Accuracy: 86.7%**
- Weakest category: Income (75% precision) — generic credits like "REFUND CREDIT" or UPI credit descriptions are genuinely ambiguous even for a human, since they lack strong category-specific keywords.
- Strongest categories: Food and Travel, where merchant names (SWIGGY, UBER, IRCTC) are highly distinctive.

The dataset used for training is synthetic (generated by `01_generate_data.py`) but deliberately includes typos, generic UPI/POS descriptions, and overlapping categories (e.g. Netflix appears in both Bills and Entertainment) to simulate real-world messiness rather than an artificially easy dataset.

## Tech stack

Python · pandas · scikit-learn (TF-IDF, Multinomial Naive Bayes) · Streamlit

## Running it locally

```bash
pip install -r requirements.txt

# 1. Generate sample training data
python 01_generate_data.py

# 2. Train the classifier
python 02_train_classifier.py

# 3. (Optional) Clean a real bank statement export
python 00_clean_bank_statement.py your_statement.csv

# 4. Launch the dashboard
streamlit run 03_dashboard.py
```

## Project structure

```
├── 00_clean_bank_statement.py   # converts raw bank exports to clean format
├── 01_generate_data.py           # generates synthetic training data
├── 02_train_classifier.py        # trains and evaluates the TF-IDF + Naive Bayes model
├── 03_dashboard.py               # Streamlit dashboard
├── sample_bank_statement.csv     # example raw bank statement format
└── requirements.txt
```

Note: trained model files (`*.pkl`) and generated CSVs are not committed — run the scripts above to regenerate them locally.

## Possible extensions
